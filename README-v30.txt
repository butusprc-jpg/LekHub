LekHub FIX v30

แก้ 2 จุดที่แจ้ง:
1) ปุ่ม “ทบทวนก่อนส่ง”
   - กดเปิดหน้าทบทวนได้ทันทีเมื่อมีรายการ
   - ไม่ถูกล็อกเพราะ LINE profile โหลดช้า
   - ตอนกด “บันทึกส่ง” ถ้า LINE ยังไม่พร้อม จะแสดงข้อความชัดเจนแทนการกดแล้วเงียบ

2) เข้าหน้าตั้งค่าไม่ได้
   - ตัดระบบ email login ออกจากหลังบ้าน
   - ใช้ LINE LIFF access token ตรวจตัวตน
   - Supabase มี session สำหรับ LINE admin โดยตรง
   - แอดมินคนแรกที่เข้าหลังบ้านจะถูกตั้งเป็น owner อัตโนมัติ
   - หลังจากมี owner แล้ว LINE คนอื่นจะเข้าไม่ได้จนกว่าจะถูกเพิ่มเป็น admin
   - ไม่ต้องใช้ ADMIN_SESSION_SECRET
   - ไม่ต้องใช้ SUPABASE_SERVICE_ROLE_KEY สำหรับหน้า admin ชุดนี้

Supabase migration ที่ v30 ต้องใช้ ถูกติดตั้งในโปรเจกต์ production แล้วในระหว่างการแก้ครั้งนี้
