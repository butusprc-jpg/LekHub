# v1.0 — Auto Receipt Points
- หลังบ้านมีแท็บ “ตั้งค่าแต้ม”
- กำหนดสูตรแบบ “กี่บาท = กี่แต้ม”
- สมาชิกสแกนใบเสร็จแล้ว OCR อ่านยอด/เลขบิล
- อ่านสำเร็จ → อัปโหลดบิล → เพิ่มแต้มอัตโนมัติทันที
- ไม่มีปุ่มให้ลูกค้ากดรับแต้ม
- แต้มเด้งขึ้นกลางหน้าจอทันที
- เลขใบเสร็จเดิมใช้ซ้ำไม่ได้
- สูตรแต้มเก็บใน Supabase และเปลี่ยนได้จากหลังบ้าน
