# LekHub Cafe WebApp v0.3

เพิ่มหลังบ้านสำหรับ staff/admin/owner/super_admin

- Dashboard สรุปจองวันนี้ สมาชิก งานเลี้ยง และบิลรอตรวจ
- จัดการสถานะการจอง: ยืนยัน / เข้าร้าน / เสร็จสิ้น / ยกเลิก
- รายชื่อสมาชิก แต้ม จำนวนบิล และยอดใช้จ่าย
- ใช้ Supabase RPC/RLS เดิม
- สมาชิกทั่วไปไม่เห็นเมนูหลังบ้าน

หมายเหตุ: ระบบสมาชิก v0.2 ต้องเปิด Anonymous Sign-Ins ใน Supabase ก่อนใช้งาน
